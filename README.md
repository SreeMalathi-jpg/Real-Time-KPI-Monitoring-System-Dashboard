# Real-Time KPI Monitoring System Dashboard using Power BI

## 📌 Project Description

Real-Time KPI Monitoring System Dashboard using Power BI is an interactive dashboard designed to monitor key business and operational performance in real time. It tracks KPIs such as revenue, transactions, units sold, processing latency, and SLA compliance, helping users identify performance changes and make data-driven decisions quickly.

## 🎯 Objectives

- Monitor important business KPIs in a single dashboard.
- Track revenue, transactions, and units sold.
- Monitor processing latency and SLA compliance.
- Compare actual performance with KPI targets.
- Analyze performance by region and product category.
- Support data-driven decision-making.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- GitHub

## 📊 Key KPIs

- Total Revenue
- Total Transactions
- Units Sold
- Average Processing Latency
- SLA Compliance Ratio
- KPI Target Performance

## 🗂️ Data Model

The project uses a Power BI star-schema data model consisting of:

- Fact_StreamingSales
- Dim_Date
- Dim_Region
- Dim_Product
- Dim_KpiTargets

## 📈 Dashboard Features

- Interactive KPI cards
- Revenue analysis
- Regional performance analysis
- Product analysis
- SLA monitoring
- Processing latency monitoring
- Date and category filters
- KPI target comparison

## 🔄 Data Preparation

Power Query is used for data cleaning, transformation, column creation, and preparation of dimension tables before loading the data into the Power BI data model.

## 🧮 DAX

DAX measures are used to calculate important KPIs and performance metrics such as:

- Total Revenue
- Total Transactions
- Total Units Sold
- Average Latency
- SLA Compliance Ratio
- Target Variance
